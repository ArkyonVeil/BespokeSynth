Title: SongCanvas Exp V4.4

- Cloning note elements now works correctly
- Double clicking a note now selects its associated rack
- Sampler now quits early if the transport line is moved off of it
- Fixed loop region showing up as active when not
- Fixed a viewport out-of-bounds bug
- Enablers now sustain if overlapping or connected
- Enabler note graphics are now updated if they're inverted
- Added a subtle highlight when hovering over a canvas element. (The place hint is also hidden when hovering an element to suggest cloning)
- Resetting or setting time to 0 now allows samplers(and others) to activate correctly on time 0.
